# VYRO Premium Interface

Je veux créer le site officiel de VYRO Premium, une application IPTV moderne destinée principalement à Android TV, Google TV et Amazon Fire TV.

Le site doit s'inspirer de la qualité visuelle et de la structure de https://nuvio.tv/, mais il ne faut PAS copier le site, ses textes, son branding, son code ou ses visuels.

Je veux reprendre son approche :

design très premium et minimaliste ;

grandes sections aérées ;

présentation du produit principalement à travers l'interface de l'application ;

fond sombre ;

animations discrètes ;

typographie moderne ;

très peu de bordures ;

grandes captures d'écran de l'application ;

mise en avant des appareils compatibles ;

explications simples plutôt que des blocs remplis de texte.

Cependant, contrairement à Nuvio, VYRO Premium est un produit commercial.

L'objectif principal du site est donc :

Découvrir l'application → comprendre ses avantages → choisir une offre → acheter un accès → créer/ouvrir son compte → télécharger VYRO Premium.

IDENTITÉ VISUELLE

Créer une identité haut de gamme correspondant à VYRO Premium.

Direction :

fond principal presque noir ;

gris anthracite très foncé ;

blanc pour les textes principaux ;

gris clair pour les textes secondaires ;

violet VYRO comme couleur d'accent ;

légers halos violets derrière certains éléments ;

gradients très subtils ;

aucun fond violet massif ;

aucun effet gaming excessif.

Le site doit évoquer :

Netflix / Apple TV / Plex / Nuvio / interfaces TV premium.

Mais il doit conserver sa propre identité.

Éviter absolument :

énormes cartes arrondies partout ;

boutons "pill" excessifs ;

gradients multicolores ;

glassmorphism excessif ;

néons agressifs ;

dizaines de badges ;

design de site IPTV low-cost ;

tableaux d'abonnements criards ;

compteurs commerciaux artificiels ;

faux avis clients ;

faux nombre d'utilisateurs ;

animations envahissantes.

Utiliser des angles légèrement arrondis, environ 8 à 14 px maximum selon les éléments.

Le design doit être extrêmement propre.

VISUEL PRINCIPAL

Utiliser une vraie capture de l'application lorsqu'elle sera fournie.

Ne pas utiliser de captures provenant de Netflix, Disney+, Nuvio ou d'autres applications.

Si aucune capture VYRO n'est disponible, utiliser temporairement une interface fictive générique.

Ajouter derrière la télévision un très léger halo violet.

Au scroll, possibilité d'utiliser une animation extrêmement légère :

légère augmentation d'échelle.

Pas d'animation spectaculaire.
